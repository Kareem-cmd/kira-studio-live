# KIRA Studio

English portfolio website with 60 projects across brand identity, campaigns, visual exploration, websites and UI systems.

Live: https://kareem-cmd.github.io/kira-studio-live/

## Content

45 projects and all 573 local media files imported from the owner's original portfolio at https://kareem-cmd.github.io/portfolio/. The existing KIRA archive contributes another 15 projects. Original artwork and four Vimeo films are preserved. Website interface and descriptions are English.

Project metadata lives in `data/projects.json`. Each project has a static HTML page under `projects/`; the archive is `work.html`. Media is stored locally under `portfolio-assets/`. There is no backend or build dependency.

## Publishing

GitHub Pages publishes the root of the `main` branch. `.nojekyll` preserves the static asset tree. All navigation and asset references support the repository subpath.

## Accessibility and motion

Keyboard-accessible archive filters, live result counts, native image dialogs, skip links, reduced-motion support and lazy-loaded project images. Original project art may include text in its original language.

All project imagery and brand assets belong to their respective owners. This repository is a portfolio publication, not a license to reuse those assets.
